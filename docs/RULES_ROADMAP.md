# Rules roadmap

## For all Road Kings owners

| Phase | Goal | Status |
|-------|------|--------|
| **1 — Minimal play** | Credits, start, ball in play, outhole, ball end, basic audit tests | In progress |
| **2 — Original rules** | Recreate factory Road Kings ruleset from manual | Planned |

Phases 1–2 are **optional to customize**; the codeset remains useful as a Sys 11 RPU base without them.

## Max Rockatansky customization (this fork)

| Phase | Goal | Status |
|-------|------|--------|
| **3 — Theme** | Road Warrior / *Furiosa* inspired modes, multiballs, callouts | Idea / design in root README |

Theme work should not change machine-invariant switch IDs in [ROAD_KINGS.md](ROAD_KINGS.md) without documenting factory vs custom behavior.

## Out of scope (until later)

- Full WAV library for theme callouts
- Lamp animation polish for all playfield effects
- Tournament / league-specific rule variants
